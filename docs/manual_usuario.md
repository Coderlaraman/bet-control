# Manual de Usuario - Sistema de Control de Apuestas RushBet

## Introducción

Este sistema está diseñado para ayudarte a controlar y analizar tus apuestas deportivas en la plataforma RushBet de manera profesional y automatizada. El sistema te permite registrar apuestas, hacer seguimiento de tu bankroll, y obtener análisis detallados de tu rendimiento.

## Características Principales

### 1. Gestión de Apuestas
- Registro de apuestas simples y combinadas
- Control detallado con información de deporte, liga, mercado, evento, y más
- Seguimiento de estado (pendiente, ganada, perdida, anulada)
- Cálculo automático de ganancias potenciales

### 2. Control Automático de Bankroll
- Ajuste automático del bankroll al realizar apuestas
- Actualización automática según resultados
- Límites configurables (máximo porcentaje por apuesta, montos mínimos/máximos)
- Historial completo de transacciones

### 3. Análisis y Reportes
- Estadísticas detalladas por deporte, liga, tipo de apuesta
- Análisis de ROI (Retorno de Inversión)
- Tasa de acierto (win rate)
- Gráficos y visualizaciones interactivas
- Exportación de datos

### 4. Seguridad
- Autenticación segura con JWT
- Gestión de usuarios con roles
- Protección de datos sensibles

## Guía de Uso

### Primeros Pasos

1. **Registro de Usuario**: Crea tu cuenta en el sistema
2. **Configuración de Bankroll**: Establece tu bankroll inicial y límites
3. **Registro de Apuestas**: Comienza a registrar tus apuestas

### Registro de Apuestas

Para registrar una nueva apuesta:

1. Haz clic en "Nueva Apuesta"
2. Completa el formulario con:
   - **Información del Evento**: Deporte, liga, país, equipos
   - **Detalles de la Apuesta**: Tipo de apuesta, mercado, descripción
   - **Montos**: Stake (monto apostado) y cuotas
   - **Fecha y Hora**: Cuándo se juega el evento
3. El sistema calculará automáticamente las ganancias potenciales
4. El monto se deducirá automáticamente de tu bankroll

### Seguimiento de Resultados

Cuando se resuelva una apuesta:

1. Actualiza el estado en el sistema
2. El bankroll se ajustará automáticamente
3. Se actualizarán las estadísticas

### Análisis de Rendimiento

Accede al dashboard para ver:
- Resumen general de tu bankroll
- Gráficos de rendimiento
- Estadísticas por deporte/liga
- Historial de apuestas
- Análisis de ROI

## Configuración de Límites

Es importante establecer límites responsables:

- **Porcentaje Máximo por Apuesta**: No más del 5% del bankroll
- **Monto Mínimo**: Apuesta mínima permitida
- **Monto Máximo**: Límite superior por apuesta

## Mejores Prácticas

1. **Registro Inmediato**: Registra las apuestas justo después de realizarlas
2. **Actualización de Resultados**: Actualiza los resultados tan pronto como estén disponibles
3. **Revisión Regular**: Analiza tus estadísticas semanalmente
4. **Gestión Responsable**: Nunca apuestes más de lo que puedas permitirte perder
5. **Análisis de Datos**: Usa los reportes para identificar patrones y mejorar tu estrategia

## Solución de Problemas

### Problemas Comunes

**No puedo iniciar sesión**
- Verifica tu nombre de usuario y contraseña
- Asegúrate de estar registrado

**El bankroll no se actualiza**
- Verifica que las apuestas estén correctamente registradas
- Asegúrate de actualizar los resultados

**No puedo registrar una apuesta**
- Verifica que tengas fondos suficientes
- Asegúrate de que el monto esté dentro de los límites configurados

### Soporte Técnico

Para problemas técnicos, contacta al administrador del sistema.

## Consejos para el Éxito

1. **Mantén la Disciplina**: Sigue tu estrategia y límites establecidos
2. **Analiza tus Datos**: Usa las estadísticas para mejorar
3. **Gestiona tu Bankroll**: Nunca arriesgues demasiado en una sola apuesta
4. **Aprende de tus Errores**: Revisa las apuestas perdidas para entender qué salió mal
5. **Mantén Registros Precisos**: La calidad de los datos determina la calidad del análisis
